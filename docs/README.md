# Machine-Day Composer Documentation

This directory contains system architecture, design specifications, and implementation documentation for the Machine-Day Composer platform.

## Planned Documentation Structure

- **Architecture:** System topology, component interactions, and data flows.
- **Domain Model:** Custom Hiring Centre (CHC) entities, machinery specifications, machine-day allocations, and breakdown-recovery state machines.
- **Database & Migrations:** Schema design, ER diagrams, and Alembic migration guidelines.
- **API Reference:** OpenAPI contracts and endpoint specifications.
- **Workflows:** Step-by-step documentation for scheduling algorithms, breakdown reporting, and recovery re-dispatching.
